MISSING PIXELS
------------------------------------------------------------------------------
Lost downlink packets leave pixels at exactly 0. Each packet carries ~493
contiguous pixels in raster order, so gaps appear as horizontal row segments.
Column 0 is a structural dead column present in every frame (100 px) and is
also filled. nimgpkts/446 gives the fraction of packets received.

REJECTION CRITERION
------------------------------------------------------------------------------
A frame is discarded if either:
  (a) max_dist > 3 px  - some missing pixel lies further than 3 px from any
      real pixel, so local interpolation has nothing nearby to work from; or
  (b) missing > 20% of the frame. The distribution has a natural break here:
      the kept frames top out at 13.96% and the next-worst is 27.16%.

Validated against ground truth: real loss masks were applied to the complete
(446-packet) frames, interpolated, and compared with the known values. Error
in the extracted 1-D spectrum (cross-dispersion median over the trace):

   frames kept     : p95 error <= 2.0%, worst bin <= 5.6%
   frames rejected : up to 4.1% p95, worst bin 38%, and for the ~60%-loss
                     frames ~38 wavelength bins exceed 5% error

INTERPOLATION METHOD
------------------------------------------------------------------------------
Two stages, using only surrounding pixel data:
  1. normalised convolution (Shepard) propagating inward from gap edges;
  2. Jacobi relaxation of the Laplace equation with real pixels held fixed,
     giving a harmonic interpolant across each gap.

Radiation hits are dense in these frames (~11% of pixels exceed median+6 sigma;
frame median ~4430 ADU, p99 ~45000). Such pixels are EXCLUDED as interpolation
sources - using them pulls filled values wildly off - but are left untouched in
the output. Interpolated regions therefore carry the local continuum and contain
no synthetic cosmic rays, by design.

Only pixels that were missing are replaced; every other pixel is bit-identical
to the raw frame (verified for all 41 frames). Output stays uint16, clipped to
1..65534 so 0 (missing) and 65535 (hot) remain unambiguous. Extension FILLMASK
flags interpolated pixels (1 = interpolated). Headers carry NFILLED, FILLFRAC,
FILLMETH, FILLMAXD, FILLSRC and HISTORY.

NOT CORRECTED: hot/saturated pixels (65535) and radiation hits are left in place;
they need the usual cosmic-ray rejection downstream.
